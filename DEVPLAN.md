# Dental Intake Pilot Project

- local storage (IndexedDB) only for first iteration
- get confirmation that interfaces are adequate fro use in the real world
- once confirmed, add synchronization steps through Nostr

- Synchronize stores with Nostr across devices
- Publish anonymized schedule data to Nostr
- Patients register their own profiles, and send their data to Nostr
- Patients can "request" a encounter from doctor
- Doctors "approve" or "deny" a patient's request
